# Specs

Design documents that are longer than an ADR and narrower than the architecture.

A0 wrote no specs: everything A0 decided is either an ADR (a decision with alternatives
rejected), the architecture document (the shared context), or a module docstring (a
normalisation that must be reimplementable).

Agents who need one: name the file after the thing it specifies, not after yourself, and
link it from your package doc.
